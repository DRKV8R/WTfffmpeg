Service Configuration Error

The video creation service is not properly configured

{{ error_message }}

🔍 What's happening?

The WTfffmpeg service requires certain environment variables to be configured before it can create videos. This is a deployment configuration issue that needs to be resolved by an administrator.

For Users:

  • This is not an error with your files or request
  • The service administrator needs to complete the deployment configuration
  • Please contact your administrator or try again later

🛠️ For Administrators

Quick Diagnostics:

✓ Service Health: Check health endpoint
✗ Configuration: Check configuration endpoint

Likely Cause:

The CLOUD_STORAGE_BUCKET environment variable is not set in the deployment.

Solution:

Set the required environment variable in your Cloud Run deployment:

gcloud run services update YOUR_SERVICE_NAME \
  --region=YOUR_REGION \
  --set-env-vars="CLOUD_STORAGE_BUCKET=your-bucket-name"

Verification:

After updating the configuration, verify the fix:

curl https://YOUR_SERVICE_URL/_config

Should return HTTP 200 with "ready_for_video_creation": true
